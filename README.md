# pi-skill-pr

[![Pi Package](https://img.shields.io/badge/pi--package-skill-blue)](https://github.com/IgorGuariroba/pi-skill-pr)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**pr** skill for the **[Pi coding agent](https://pi.dev)**, adapted from Matt Pocock's Engineering Skills.

> Use when writing a PR body.

---

## Installation

Install directly into Pi using `pi install`:

```bash
pi install git:github.com/IgorGuariroba/pi-skill-pr
```

Or clone into your local/global skills directory:

```bash
# Global Pi skills directory:
git clone https://github.com/IgorGuariroba/pi-skill-pr.git ~/.pi/agent/skills/pr

# Or Agent Skills standard path:
git clone https://github.com/IgorGuariroba/pi-skill-pr.git ~/.agents/skills/pr
```

---

## Usage

Trigger it explicitly in your session:

```text
/skill:pr
```

Or let Pi automatically route to it based on conversation context and need.
